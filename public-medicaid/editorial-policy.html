Trust and transparency

Editorial standards and source policy

We aim to make complex Medicaid policy easier to navigate without presenting this guide as an official government source or an eligibility authority.

Source hierarchy

  1. Federal statutes, regulations, CMS guidance, and official CMS announcements.
  2. Official state Medicaid agency announcements, member guidance, notices, and program pages.
  3. Nonpartisan policy research and established health-policy reporting when official state information is not yet available.

State status labels

  • State announced participation: a state agency has publicly announced that it plans to use the optional hold-harmless period. This label does not mean CMS approval has been independently verified.
  • State announced intent: a state has announced a plan or intention to request the option; the request or approval may still be pending.
  • No election verified: this guide has not verified a public announcement. It does not mean the state declined.
  • State announced it will not participate: used only when a reliable source directly supports that status.

Review and corrections

State policy can change quickly. Each state record includes a review date and source link. We prioritize official state and federal sources and will revise records when new authoritative information becomes available. If you identify an error, contact contact@radiantmotivenavigator.com with the state, statement, and supporting official source.
