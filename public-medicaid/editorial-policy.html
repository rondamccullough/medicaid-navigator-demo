Trust and transparency

Editorial standards and source policy

We organize complex public-program information into plain-language navigation steps. We do not present this guide as an official government source or as an eligibility authority.

Source hierarchy

  1. Federal and state statutes, regulations, agency guidance, official notices, and official program announcements.
  2. Official state, local, tribal, and territorial agency program pages and contact directories.
  3. Nonpartisan policy research and established reporting when official information is unavailable or needs context. Secondary sources are identified as such.

Medicaid state status labels

  • State announced participation: a state has publicly announced that it plans to use the optional hold-harmless period. This does not mean CMS approval has been independently confirmed.
  • State announced intent: a state has announced an intention or plan to request the option; the request or approval may still be pending.
  • No election verified: this tracker has not verified a public hold-harmless announcement. It does not mean the state declined or that the federal requirement applies in the state.
  • CMS page says requirement does not apply: the current CMS state-specific page contains a statement that the new requirement does not apply in that state. This is an official state-page applicability statement, not a hold-harmless election; it must be rechecked against current CMS and state guidance.
  • State announced it will not participate: used only when a reliable source directly supports that status.

Review and corrections

State and program information can change. We display review dates and source links where available. We prioritize official sources and revise records when new authoritative information is confirmed. If you identify an error, contact contact@radiantmotivenavigator.com with the page, statement, and supporting official source.
